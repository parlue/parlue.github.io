# parlue – GitHub Project Portfolio

Portfolio-Seite für:

- BluetoothMax
- CynusLink
- Centaur_PGN

## Bilder / Videos austauschen

Die Platzhalter liegen unter `assets/project-1.svg` bis `project-3.svg`.
Du kannst sie durch eigene JPG-, PNG-, WebP- oder GIF-Dateien ersetzen
und anschließend die Pfade in `index.html` ändern.

Für Videos kann ein `<video>`-Block oder ein YouTube/Vimeo-Embed ergänzt werden.

## Buy me a tea

Der Button ist aktuell auf `https://www.buymeacoffee.com/parlue` gesetzt.
Falls dein tatsächlicher Support-Link anders lautet, ändere ihn in `index.html`.

## GitHub Pages

Repository erstellen oder verwenden, Dateien hochladen und unter
Settings → Pages die Veröffentlichung aus dem gewünschten Branch aktivieren.
