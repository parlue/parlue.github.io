Virgin

A UCI chess engine built for bots. Virgin is an aggressive, independent tactician; its strategic reliability still varies. Every part of its evaluation can be steered from the outside, so that character can be shaped into many different opponents.

215 ready-made bots, your own bots from a plain text file, and an adaptive mode that keeps a game winnable for the human player. One small file for Windows and Android.

GitHub ↗ How to make a bot

Virgin is open source under the MIT license. Questions? Come to the Discord server electricchess.

The idea

An engine you can shape

Most engines try to be as strong as possible. Virgin tries to be a good opponent.

Built for bots

A bot is a playing strength combined with a playing style. Virgin ships a catalogue of 215 bots (43 strength levels times 5 styles) and lets you define as many more as you like.

Every weight is adjustable

About 90 evaluation weights are exposed as UCI options and in one weights file. There is no NNUE and no opaque network: you can read, change and reload each value.

One small file

C++20 and no external libraries. The Windows binary is roughly 400 KB, the static Android binary stays under 1 MB. Windows and Android are built from the same code.

Plain UCI

Virgin is a process that speaks UCI over stdin and stdout. It works with any UCI host, such as BearChess, Arena or Cute Chess, and with your own app.

An attacking character

Virgin’s own character is a tactician that looks for the attack. Strategic reliability still varies, and that is part of what makes the bots feel different from each other.

Made for apps

The engine, the bot catalogue and the playing styles live in one binary, so an app only needs to start one process and send UCI commands.

Adaptive play

A game you can still win

The adaptive game of “Tal” from the app eChessTactics, built into the engine.

In adaptive mode Virgin does not try to crush its opponent. After every move it looks at the position from the human player’s point of view, analyses five candidate moves and chooses the one that keeps the game interesting and winnable. The aim is to lead the player into a position that can be won with good technique.

Opening

The first moves are the engine’s best moves, so the game starts as a normal game.

Roughly equal

Among the candidates it picks a move that keeps the balance, and now and then a different but equal one so that games do not repeat.

You are behind

It helps: it chooses a safe move that gives part of the advantage back, and it never sacrifices a queen or a rook to do it.

Far behind, or mate in sight

Full strength. No gifts when the game is clearly lost or a forced mate is near.

You are ahead

It keeps the position where it is for the rest of the game, so the win stays within reach and does not slip away.

Real tactics

When a sound tactic wins material it plays it. If you have been playing accurately in a balanced game, it may let a small advantage go, a few times per game.

Turn it on

setoption name Adaptive value true

Adaptive is a single UCI option. While it is on, Virgin ignores all the other strength and style options: it plays with full strength, five candidate moves, a fixed attacking profile and automatic threads, and the adaptive logic decides which move is played. Switching it off restores your previous settings. Because it analyses five candidates each turn, allow a few seconds per move. The engine reports every choice in an info string line: the mode it used, the evaluation from the player’s side and how accurately the player has been playing.

Make your own

Create a bot

A bot is a strength and a style. Pick one, mix one, or save your own as a text file.

The style axis is called Boldness, from cautious to reckless:

StyleMeaning
FurchtsamTimid: safety first, avoids sharp lines, accepts draws.
VorsichtigCautious: solid and positional.
AusgeglichenBalanced: the reference style, all weights at their defaults.
AngriffslustigAggressive: goes for the king, avoids queen trades.
StierBull: sacrifices, pawn storms, king hunts.

1. Pick one from the catalogue

setoption name Bot value v1200-stier

Bot ids look like v<elo>-<style>, for example v700-furchtsam, v1500-angriffslustig or v2800-ausgeglichen. The whole catalogue is in data/bots.json for apps and in data/bots.txt; virgin --list-bots prints it.

2. Mix strength and style yourself

setoption name UCI_LimitStrength value true
setoption name UCI_Elo value 1250
setoption name Style value Angriffslustig
setoption name Boldness value 45

Boldness runs from 10 (timid) to 50 (bull) and interpolates between the styles. UCI_Elo accepts any whole number from 700 to 3000, not only the 50-point steps of the catalogue.

3. Tune single weights

setoption name Aggression.KingAttack value 260
setoption name Misc.MoveNoise value 40

4. Save your bot as a weights file

A bot is just a text file with Name = value lines:

# my-bot.txt
Aggression.KingAttack = 260
Aggression.PawnStorm = 180
Aggression.AvoidQueenTrade = 220
Misc.Contempt = 25
setoption name WeightsFile value C:\bots\my-bot.txt
setoption name ReloadWeights

data/weights_default.txt lists every weight with its default and range.

Reference

UCI options and commands

All the standard UCI commands, plus the options and commands below.

Options

OptionMeaning
BotSelects a catalogue bot such as v1200-stier and sets strength and style at once.
UCI_LimitStrength, UCI_EloLimit the playing strength (700 to 3000).
Style, BoldnessThe playing style and its fine control.
AdaptiveSwitches adaptive play on or off. While it is on, all other strength and style options are ignored.
WeightsFile, ReloadWeightsLoad your own weights file.
Misc.Contempt, Misc.MoveNoiseDraw attitude and randomness in the root move choice.
Hash, Threads, PonderHash size in MB, search threads, pondering.
<Group>.<Term>Every evaluation weight is a spin option, for example Aggression.KingAttack.

Commands

CommandWhat it does
uci, isready, ucinewgameThe usual UCI handshake.
setoption, position, go, stop, quitStandard. go understands depth, nodes, movetime, wtime/btime with increments, movestogo, infinite and ponder.
dShows the board.
evalShows the evaluation with a breakdown.
perft <n>, bench <n>Move generation check and a speed benchmark.
sanityA consistency check of the engine.
weightsLists all weights.
listbotsPrints the bot catalogue.

From the command line

virgin --selftest          # built-in test run
virgin --perft 5           # must print 4865609
virgin --list-bots         # the 215 bots
virgin --gen-data          # regenerate data\ (weights, styles, bot catalogue)
